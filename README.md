# WABAM

لوحة تحكم عبر Telegram لتشغيل وإدارة بوت WhatsApp Anime Bot.

## ما الذي يفعله؟
- ربط رقم واتساب باستخدام Pairing Code وإرسال الرمز إلى Telegram.
- تشغيل وإيقاف وإعادة تشغيل عملية بوت واتساب.
- عرض حالة العملية والسجلات الأخيرة.
- حصر التحكم في Telegram ID الخاص بالمالك.
- حفظ جلسة واتساب وقاعدة البيانات على التخزين الدائم.

## هيكل المشروع
- `src/`: بوت Telegram ومدير عملية واتساب.
- `whatsapp-bot/`: ملفات مشروع WhatsApp-Anime-Bot-v1 وصور الشخصيات.
- `docs/SETUP.md`: خطوات الإعداد والاستضافة.

## إعداد سريع
1. استخدم استضافة تدعم Node.js 20 أو أحدث، والعمليات الفرعية، والتخزين الدائم.
2. أضف متغيرات `.env.example` في إعدادات الاستضافة.
3. نفّذ `npm install` ثم `npm start` من جذر المشروع.
4. افتح بوت Telegram وأرسل `/start`، ثم اختر ربط/تشغيل واتساب.

**مهم:** لا ترفع `.env` أو جلسة واتساب أو ملفات قاعدة البيانات. راجع `docs/SETUP.md` للتفاصيل.
