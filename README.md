# WABAM

لوحة تحكم Telegram لمكتبة الأنمي وإدارة بوت WhatsApp Anime Bot.

## الوظائف
- قائمة Telegram عامة لمكتبة الأنمي.
- لوحة إدارة خاصة بالمالك عبر `/admin`.
- إدارة الأنمي والأقسام والحلقات وروابط الفيديو.
- قائمة إدارة واتساب داخل لوحة الإدارة فقط: ربط، حالة، سجلات، إيقاف وإعادة تشغيل.
- بوت WhatsApp يعرض مكتبة الأنمي المشتركة عبر `.انمي`.
- قوائم WhatsApp منفصلة: `.رئيسية` و`.الألعاب` و`.بنك`.
- نظام 20 رتبة، مع صلاحيات الإدارة للرتب 17–20 والمطورين.
- نظام إنذارات وحماية، وجوائز يومية وأسبوعية.

## التخزين
- `WABAM_DATA_DIR` يجب أن يكون مسار تخزين دائم على الاستضافة.
- جلسة WhatsApp وقاعدة بياناته محفوظتان داخل مجلد `whatsapp` في مسار البيانات.
- مكتبة الأنمي المشتركة محفوظة في `shared/anime-library.json`.
- روابط الحلقات المضافة من Telegram يجب أن تكون روابط فيديو مباشرة يمكن للخادمين الوصول إليها.

## الإعداد
1. استخدم Node.js 20 أو أحدث واستضافة تدعم العمليات الفرعية والتخزين الدائم.
2. اضبط `BOT_TOKEN` و`OWNER_TELEGRAM_ID` و`WA_OWNER_NUMBER` و`WABAM_DATA_DIR` في Environment Variables.
3. نفّذ `npm install` ثم `npm start` من جذر المشروع.
4. افتح Telegram وأرسل `/start`، ثم استخدم مكتبة الأنمي أو افتح `/admin`.

**مهم:** لا ترفع `.env` أو جلسة WhatsApp أو قاعدة البيانات أو رموز الربط إلى GitHub.
